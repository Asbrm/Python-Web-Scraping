# Python Web Scraping & Data Cleaning Portfolio 🚀

A collection of Python scripts demonstrating practical skills in data extraction (Web Scraping) and data structuring (Data Cleaning) for real-world scenarios.

## 📌 Projects Included

### 1. E-commerce Product Scraper
Extracts product data (titles, prices, and stock availability) from an e-commerce platform.
*   **Data Cleaning:** Formatted raw currency strings into clean float values and standardized text availability using Pandas.
*   **Output:** `cleaned_books_data.csv`



### 2. Real Estate Data Structuring
Parses HTML property listings to extract addresses, prices, bedrooms, and bathrooms.
*   **Data Cleaning:** Leveraged **Regex** to strip text from numbers, transforming messy strings into a structured dataset.
*   **Output:** `real_estate_cleaned.csv`



## 🛠️ Technologies & Libraries Used
*   **Language:** Python 3
*   **Web Scraping:** `BeautifulSoup4`, `requests`
*   **Data Cleaning & Manipulation:** `pandas`, `re` (Regular Expressions)
